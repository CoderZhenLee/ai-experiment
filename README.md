# ¥10000 投资实验 · 公开记录网站

> 用 ¥10,000 挑战 180 天投资实验 —— 公开规则、真实记录、每日更新。
> 半年后,这套规则化策略到底有没有用,我们一起看结果。

## 🌟 现在支持的两种模式

### 1. 演示数据模式(默认 fallback)
- 打开网页即用,所有数据均为演示数据(seed 固定)
- 用于展示产品形态,可切回查看完整 UI

### 2. **真实数据模式**(推荐)
- 每天收盘后运行 `python3 update_data.py`,从**东方财富**公开接口拉取真实行情、历史 K 线、财务指标、**真实新闻、公告、券商研报**
- 五维评分(估值/盈利/成长/趋势/波动)拆解到研报级子指标(PE/PB/ROE/毛利率/营收增速/RSI/波动率/回撤 等)
- 候选池 10 只全部基于真实数据打分排名
- **新闻速览**(后台详情卡底部):每只股票最近 5 条新闻 + 3 条公告
- **研报评级**(后台详情卡底部):每只股票最近 5 条券商研报(机构/评级/标题/目标价)
- **宏观速览**(后台顶部):国际原油(WTI/布伦特)、黄金、美元指数、人民币汇率、恒生指数 —— 国际形势传导参考
- **高位警示**:52 周位置>75% 或 20 日涨幅>15% 自动标红
- **多源容错**:东财 push2/push2his 限流时自动切换到腾讯 qt.gtimg.cn / web.ifzq.gtimg.cn
- 真实交易由你手动在券商 App 执行,录入「交易执行台」,主站收益曲线按真实成交计算

## 🚀 快速开始(真实数据模式)

### 第一步:生成真实数据

```bash
cd investment-experiment
python3 update_data.py
```

脚本会输出:
```
[贵州茅台 600519] 抓取中 ...
    最新价 ¥1306.45  涨跌 -1.65%  PE(TTM) 19.84  PB 6.04  市值 16332亿
    ROE 42.28%(年化)  毛利 88.5%  营收同比 6.34%  净利同比 1.47%
    RSI 67.4  年化波动 33.58%  60日回撤 -18.43%  综合 73.7  [C 观察]
...
排名前 5(今日观察池):
   1. 招商银行  综合 76.5  [B 关注]
   ...
```

生成的文件:
- `real_data.json` — 完整数据(供程序化读取)
- `real_data.js` — JSONP 格式,网页用 script 标签加载
- `portfolio_history.json` / `portfolio_history.js` — 净值快照

### 第二步:打开网页

直接双击 `index.html` 即可(file:// 协议下也能用)。顶栏会显示:
- 🟢 **真实数据 · 2026-08-05** 徽章
- 一个「切换演示」按钮

打开 `recommend.html` 即可看到推荐后台(候选池排名、研报级拆解、交易执行台)。

### 第三步(可选):录入真实交易

1. 在券商 App 按系统生成的信号手动执行(候选池前 5 名 + 评级 A/B)
2. 打开 `recommend.html` → 「交易执行台」
3. 填表录入成交(标的/方向/数量/成交价/时间) → 自动带时间戳
4. 点击「导出成交记录 JSON」→ 得到 `trades_record.json`
5. 把文件放回 `investment-experiment/` 目录
6. 再次运行 `python3 update_data.py` → 自动并入净值快照
7. 刷新 `index.html` → 真实收益曲线自动出现

### 第四步(可选):自动定时

```bash
# macOS launchd(每天 16:00 自动更新)
cp tools/ai-exp-update.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/ai-exp-update.plist

# Linux cron
crontab -e
# 添加:0 16 * * 1-5 cd /path/to/investment-experiment && /usr/bin/python3 update_data.py
```

## 📐 评分模型(研报级拆解 · 六维)

| 维度 | 权重 | 子指标 |
|---|---|---|
| 估值 | 22% | PE(TTM) 水平 · 52周价格位置 · PB 水平 |
| 盈利能力 | 22% | 年化 ROE · 毛利率 · 现金流/净利质量 |
| 成长性 | 18% | 营收同比 · 净利同比 |
| 趋势 | 14% | 均线排列 · MA20 斜率 · RSI14 |
| 波动风险 | 14% | 年化波动率 · 60日最大回撤 |
| **新闻情绪** | **10%** | 关键词词典打分(利好/利空词 × 标题权重 × 来源权重 × 时间衰减 × 公告双倍) |

### 新闻情绪维度(盘中动态)

`python3 update_data.py --quick` 盘中快速模式(约 15 秒):只拉行情 + 新闻 + 公告,
情绪实时更新并参与综合分 —— 你可以在中午、下午 14:00 各跑一次,评估"买还是卖"。

- 情绪打分**可复现**:不是 AI 语义猜测,是规则词典(利好词/利空词)+ 权重
- 利好 N 条 / 利空 M 条 实时显示,触发信号时后台标红
- 持仓股情绪"利空"或评级 D → 卖出/风险信号

### 盘中操作流程

```
中午 12:00   python3 update_data.py --quick   → 看情绪变化,决定午后是否动手
下午 14:00   python3 update_data.py --quick   → 第二次评估,最终买/卖决策
收盘 15:30   python3 update_data.py           → 完整评分 + 净值快照
```

子指标在后台详情卡以 chip 形式展示,**真实数据 + 真实数值**,可拖动权重实时重算排名。

## 🛠 自定义

### 修改候选池
编辑 `update_data.py` 顶部的 `POOL` 列表,添加或删除股票:

```python
{"name": "你的股票", "code": "600000", "secid": "1.600000", "industry": "行业", "brief": "一句话基本面"},
```

注意 `secid` 前缀:沪市/科创板 = `1.xxx`,深市/创业板 = `0.xxx`。

### 修改评分阈值
编辑 `update_data.py` 中的 `grade_of` 与各 `score_band` 函数。

### 调整单笔仓位规则
编辑 `recommend.js` 的 `suggestQty` 函数(当前按总资产 10% ≈ ¥1,000 计算,取整手 100 股)。

## 🐛 常见问题

**Q: 打开网页显示演示数据?**
A: 没有 `real_data.js`。运行 `python3 update_data.py` 即可生成。

**Q: PE/PB 显示异常(几百倍/几千倍)?**
A: 历史 bug,已在 2026-08-05 修复(每股净资产字段不需 ×100)。重新跑脚本。

**Q: 银行股的毛利率为 `—`,影响评分?**
A: 设计上缺失数据用中性分(50)。脚本会自动处理。

**Q: 季度 ROE 年化太激进?**
A: 脚本按报告期月份年化(Q1×4、H1×2、Q3×4/3)。你可以在 `score_band` 中调整阈值,或在 `update_data.py` 中改年化系数。

**Q: 交易台数据存在哪?**
A: 浏览器 localStorage(`exp_trades_v1`)。务必用「导出」功能保存到 JSON,放回项目目录运行脚本 —— 这样多设备/多浏览器也能同步。

**Q: 想接付费数据源(tushare/akshare)?**
A: 把 `update_data.py` 中的 `fetch_quote` / `fetch_kline` / `fetch_finance` 替换为对应数据源,保持输出字段一致即可。
