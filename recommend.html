为什么推荐这几只股票?

候选池 → 五维打分 → 加权综合 → 排名 → 前 5 名进入观察池。这里展示每一步、每一分是怎么来的。

数据结构

真实模式数据集中在 real_data.json(由 update_data.py 自动生成);演示数据在 data.js。

  • update_data.py — 拉取真实行情/K线/财务,计算研报级子指标并评分
  • real_data.json — 真实模式数据源:pool(10只)+ scores + benchmark + 子指标明细
  • trades_record.json — 你的真实成交记录(从交易执行台导出)
  • portfolio_history.json — 每日净值快照,主站真实曲线数据源
  • data.js — 演示数据(展示产品形态,可随时切回)

方式一 · 手动更新(零成本)

  1. 每天收盘后,打开 data.js
  2. 按当日行情更新每只股票的 dims 五维分与 trades 价格
  3. 保存,刷新页面即可 —— 主站与后台同步生效

方式二 · 脚本半自动(推荐)

  1. 用 Python 脚本拉行情(新浪/腾讯免费接口,或券商/付费数据源)
  2. 按模型公式计算五维分:PE 分位 → 估值、ROE → 盈利、营收增速 → 成长、均线/动量 → 趋势、波动率 → 波动
  3. 脚本输出 data.js,配合定时任务每天自动更新

方式三 · 全自动后端(规模化)

架构:Python 策略服务 定时拉行情 → 计算评分 → 写入 PostgreSQL;Node/Next.js 后端提供 JSON API;index.html 改为 fetch 接口数据。 配合后台管理系统,推荐记录带固定时间戳入库,确保“事后不可修改”。
